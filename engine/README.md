# MEHRAN MUSIC AI · Independent Engine

این پروژه از این نسخه به مسیر توسعهٔ کاملاً اختصاصی MEHRAN تغییر کرده است. هیچ موتور آمادهٔ تولید موسیقی، ACE-Step، API خارجی یا سرویس پولی در مسیر فعال تولید استفاده نمی‌شود.

## وضعیت واقعی فعلی

- هستهٔ مستقل تحلیل اولیهٔ شعر فارسی و ساخت طرح آهنگ در `mehran_music_core.py`
- استخراج تقریبی تعداد هجاها، پایان واژه‌ها و نشانه‌های احساسی شعر
- پیشنهاد گام، مُد، تمپو، توالی آکورد، ساختار بخش‌ها و طرح اولیهٔ ملودی
- طرح تنظیم پویا برای پیانو، گیتار، بیس، درام، استرینگ و گیتار الکتریک
- کنترل‌پلین محلی Python و SQLite برای نگهداری پروژه‌ها
- بدون API خارجی، دانلود مدل یا fallback پولی
- **هنوز فایل صوتی تولید نمی‌شود.** خروجی فعلی یک نقشهٔ آهنگسازی ساختاریافته است، نه آهنگ نهایی و نه مدل آموزش‌دیدهٔ هوش مصنوعی.

## هستهٔ مستقل

ماژول `engine/mehran_music_core.py` فقط از کتابخانهٔ استاندارد Python استفاده می‌کند و دو ورودی اصلی دارد:

- `analyze_lyrics(lyrics)`: تحلیل اولیهٔ شعر فارسی
- `compose_plan(lyrics, title, genre, target_bpm)`: ساخت نقشهٔ آهنگ شامل گام، مُد، BPM، آکوردها، بخش‌بندی و نت‌های پیشنهادی MIDI

شمارش هجا در فارسی فعلاً تخمینی است؛ برای اجرای دقیق شعر به لایهٔ آوانویسی، تلفظ و وزن عروضی نیاز داریم. خروجی ملودی نیز طرح نت است و هنوز به فایل MIDI یا WAV تبدیل نمی‌شود.

## مراحل ساخت فناوری خودمان

1. بهبود تحلیل فارسی: آوانویسی، هجا، تکیه، وزن، قافیه و معنا
2. آهنگسازی: ملودی، هارمونی، voice-leading و فرم متناسب با شعر
3. خروجی MIDI استاندارد و ویرایش‌پذیر
4. ساخت بانک صدای اختصاصی سازها و نمونه‌برداری مجاز
5. موتور رندر چندسازه‌ای و زمان‌بندی اجرای سازها
6. میکس، مسترینگ و خروجی WAV
7. پژوهش و آموزش مدل‌های اختصاصی برای وکال و تولید موسیقی، با داده و مجوز روشن

## اجرای تست‌ها

```bash
python3 -m unittest discover -s engine -p 'test_*.py' -v
```

نیازی به نصب پکیج شخص ثالث برای هستهٔ فعلی نیست.

## کنترل‌پلین محلی

سرویس `engine/server.py` فقط روی `127.0.0.1` گوش می‌دهد، پروژه‌ها را در SQLite نگه می‌دارد و تا زمانی که رندرر صوتی واقعی ساخته و تست نشده باشد، `POST /v1/jobs` را با وضعیت `503` متوقف می‌کند. هیچ درخواست تولید صوری یا هزینه‌ای ثبت نمی‌شود.

برای اجرا، Python 3.10 یا جدیدتر لازم است:

```bash
export MEHRAN_STUDIO_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(48))')"
python3 engine/server.py
```

در Windows PowerShell:

```powershell
$env:MEHRAN_STUDIO_TOKEN = python -c "import secrets; print(secrets.token_urlsafe(48))"
python engine/server.py
```

**اصل معماری:** مالکیت مسیر آهنگسازی، کد، فرمت‌های میانی، بانک صدا و رندرر با MEHRAN است. ساخت مدل عصبی اختصاصی نیازمند دادهٔ آموزشی، آزمایش و توان پردازشی است؛ این نیاز را با ادعای آماده‌بودن مدل پنهان نمی‌کنیم.
