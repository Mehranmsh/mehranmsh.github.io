# MEHRAN MUSIC STUDIO · Local Control Plane

این بخش، پایهٔ زیرساخت مستقل استودیو است. سرویس با Python استاندارد و SQLite اجرا می‌شود و برای مدیریت پروژه‌ها به سرویس ابری یا API خارجی متصل نمی‌شود.

## وضعیت واقعی در این نسخه

- ذخیره‌سازی پروژه‌ها در SQLite محلی
- API محلی برای سلامت سرویس و ایجاد/فهرست پروژه‌ها
- احراز هویت با توکن مالک
- محدودیت اندازه درخواست، تعداد پروژه و حداقل فضای آزاد دیسک
- پیش‌فرض اتصال فقط به `127.0.0.1`
- هیچ تماس خارجی، خرید اعتبار، اشتراک یا fallback پولی وجود ندارد
- موتور تولید صدا هنوز نصب و اعتبارسنجی نشده است؛ درخواست تولید عمداً با پاسخ `503` رد می‌شود و هیچ job یا هزینه‌ای ایجاد نمی‌کند.

## اجرا

Python 3.10 یا جدیدتر لازم است. هیچ dependency شخص ثالثی نصب نمی‌شود.

Linux / macOS:

```bash
export MEHRAN_STUDIO_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(48))')"
python3 engine/server.py
```

Windows PowerShell:

```powershell
$env:MEHRAN_STUDIO_TOKEN = python -c "import secrets; print(secrets.token_urlsafe(48))"
python engine/server.py
```

سرویس به‌صورت پیش‌فرض فقط روی همین دستگاه در `http://127.0.0.1:8765` در دسترس است. برای فراخوانی API هدر `Authorization: Bearer <token>` لازم است. توکن را در مخزن Git یا کد مرورگر قرار ندهید.

متغیرهای اختیاری:
- `MEHRAN_STUDIO_HOME`: مسیر داده‌ها؛ پیش‌فرض `~/.mehran-music-studio`
- `MEHRAN_STUDIO_HOST`: پیش‌فرض `127.0.0.1`؛ فقط IP حلقه‌بسته IPv4 پذیرفته می‌شود و آدرس شبکه‌ای/عمومی حتی با تنظیم دستی هم رد خواهد شد
- `MEHRAN_STUDIO_PORT`: پیش‌فرض `8765`
- `MEHRAN_STUDIO_MAX_PROJECTS`: پیش‌فرض 500
- `MEHRAN_STUDIO_MIN_FREE_BYTES`: حداقل فضای آزاد، پیش‌فرض 2 GiB

## بررسی سخت‌افزار بدون دانلود یا هزینه

قبل از انتخاب مدل، روی دستگاهی که قرار است موتور روی آن اجرا شود این دستور را اجرا کنید:

```bash
python3 engine/preflight.py
```

گزارش CPU، RAM، GPU قابل‌شناسایی و فضای ذخیره‌سازی را به‌صورت محلی چاپ می‌کند. هیچ فایلی از اینترنت دانلود نمی‌شود و هیچ API یا سرویس پولی فراخوانی نمی‌شود.

## مدل پایه و سیاست مجوز

مدل اصلی در صف ارزیابی **ACE-Step 1.5** است. مخزن رسمی و کارت مدل Hugging Face مجوز MIT را اعلام کرده‌اند و مخزن رسمی امکانات تولید آهنگ کامل، موسیقی بی‌کلام، ترانه چندزبانه، ویرایش صوت و جداسازی ترک را مستند کرده است. این فقط انتخاب نامزد است، نه اعلام نصب یا تأیید عملکرد روی سخت‌افزار ما.

- مخزن رسمی: https://github.com/ace-step/ACE-Step-1.5
- کارت مدل: https://huggingface.co/ACE-Step/Ace-Step1.5
- راهنمای رسمی: Python 3.11 تا 3.12 و پشتیبانی CUDA، ROCm، Intel XPU، Apple Silicon MPS و CPU.
- مدل‌های 2B گزینه‌های کم‌حافظه‌تری دارند؛ مدل‌های XL با 4B پارامتر به حداقل 12GB VRAM همراه offload و quantization یا حدود 20GB بدون offload نیاز دارند.
- وزن‌های MusicGen به‌دلیل مجوز CC-BY-NC 4.0 از مسیر تجاری MEHRAN کنار گذاشته شده‌اند؛ MIT بودن کد به معنی MIT بودن وزن‌ها نیست.
- پیش از نصب هر مدل، مجوز همان نسخه، همه وزن‌های جانبی، وابستگی‌ها و شرایط استفاده تجاری باید جداگانه بازبینی شوند.

## اتصال آزمایشی به API محلی ACE-Step

قرارداد رسمی ACE-Step از `POST /release_task` برای ثبت کار، `POST /query_result` برای پیگیری و `GET /v1/models` برای فهرست مدل‌ها استفاده می‌کند. راهنمای رسمی: https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/API.md

ما یک آداپتور محدود در `engine/acestep_client.py` آماده کرده‌ایم:

- فقط `localhost` یا IP loopback را قبول می‌کند؛ آدرس عمومی و redirect رد می‌شود.
- برای هر درخواست سقف زمان و اندازه پاسخ دارد.
- تعداد تولید هم‌زمان را به یک خروجی در هر درخواست محدود می‌کند.
- مدت، BPM، زبان، طول prompt و lyrics را قبل از ارسال بررسی می‌کند.
- API key فقط برای سرور محلی ACE-Step از طریق header قابل تنظیم است.
- این آداپتور هنوز به مسیر تولید عمومی متصل نیست. `POST /v1/jobs` تا تکمیل نصب مدل، آزمون سخت‌افزار و پذیرش نهایی همچنان بسته است.

## قفل مجوز و صحت مدل

فهرست مدل‌ها در `engine/model_catalog.json` است. `engine/model_policy.py` فقط مدل‌های مجاز را می‌پذیرد و برای فعال‌سازی محلی این موارد را اجباری می‌کند:

- مجوز مجاز و بازبینی‌شده برای همان مدل و وزن‌های جانبی
- تأیید صریح مالک
- فایل‌های مدل موجود در پوشه محلی، بدون مسیرهای خروج از پوشه
- SHA-256 معتبر برای هر فایل ثبت‌شده
- موفقیت self-test

حتی manifest معتبر نیز موتور را آماده اعلام نمی‌کند؛ تا زمانی که runner واقعی متصل و تست نشده باشد، درخواست تولید بسته می‌ماند.

## API

- `GET /health`: وضعیت کنترل‌پلین، مدل محلی و فضای آزاد
- `GET /v1/projects`: فهرست پروژه‌ها
- `GET /v1/projects/{id}`: جزئیات یک پروژه
- `POST /v1/projects`: ایجاد پیش‌نویس پروژه با JSON
- `PUT /v1/projects/{id}`: ویرایش پروژه و وضعیت آن (`draft`، `ready`، `archived`)
- `DELETE /v1/projects/{id}`: حذف پروژه با احراز هویت مالک
- `POST /v1/jobs`: تا زمان نصب و آزمون موتور محلی، عمداً `503` برمی‌گرداند؛ job ساخته نمی‌شود و هزینه‌ای ثبت نمی‌شود.

## مسیر توسعه بعدی

۱. تکمیل API و اتصال امن رابط استودیو به این کنترل‌پلین  
۲. طراحی قرارداد runtime و صف محدود پردازش  
۳. ارزیابی مدل‌های متن‌باز تولید موسیقی و مجوز استفادهٔ تجاری آن‌ها  
۴. نصب مدل فقط روی سخت‌افزار تحت کنترل MEHRAN و اجرای آزمون‌های محلی  
۵. فعال‌سازی jobها فقط پس از تست سلامت، محدودیت منابع و توقف قطعی در سقف مصرف

نکته: نرم‌افزار متن‌باز هزینهٔ مجوز/API را حذف می‌کند، اما برق، سخت‌افزار، اینترنت و فضای ذخیره‌سازی همچنان منابع واقعی‌اند. این کنترل‌پلین برای عبور از سقف منابع، پرداخت خودکار یا سرویس جایگزین پولی طراحی نشده است.
