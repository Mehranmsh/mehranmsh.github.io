# MEHRAN MUSIC STUDIO · Local Control Plane

این بخش، پایهٔ زیرساخت مستقل استودیو است. سرویس با Python استاندارد و SQLite اجرا می‌شود و برای مدیریت پروژه‌ها به سرویس ابری یا API خارجی متصل نمی‌شود.

## وضعیت واقعی در این نسخه

- ذخیره‌سازی پروژه‌ها در SQLite محلی
- API محلی برای سلامت سرویس و ایجاد/فهرست پروژه‌ها
- احراز هویت با توکن مالک
- محدودیت اندازه درخواست، تعداد پروژه و حداقل فضای آزاد دیسک
- پیش‌فرض اتصال فقط به `127.0.0.1`
- هیچ تماس خارجی، خرید اعتبار، اشتراک یا fallback پولی وجود ندارد
- موتور تولید صدا هنوز نصب و اعتبارسنجی نشده است؛ درخواست تولید عمداً با پاسخ `503` رد می‌شود و هیچ job یا هزینه‌ای ایجاد نمی‌کند.

## اجرا

Python 3.10 یا جدیدتر لازم است. هیچ dependency شخص ثالثی نصب نمی‌شود.

Linux / macOS:

```bash
export MEHRAN_STUDIO_TOKEN="$(python3 -c 'import secrets; print(secrets.token_urlsafe(48))')"
python3 engine/server.py
```

Windows PowerShell:

```powershell
$env:MEHRAN_STUDIO_TOKEN = python -c "import secrets; print(secrets.token_urlsafe(48))"
python engine/server.py
```

سرویس به‌صورت پیش‌فرض فقط روی همین دستگاه در `http://127.0.0.1:8765` در دسترس است. برای فراخوانی API هدر `Authorization: Bearer <token>` لازم است. توکن را در مخزن Git یا کد مرورگر قرار ندهید.

متغیرهای اختیاری:
- `MEHRAN_STUDIO_HOME`: مسیر داده‌ها؛ پیش‌فرض `~/.mehran-music-studio`
- `MEHRAN_STUDIO_HOST`: پیش‌فرض `127.0.0.1`، آن را عمومی نکنید
- `MEHRAN_STUDIO_PORT`: پیش‌فرض `8765`
- `MEHRAN_STUDIO_MAX_PROJECTS`: پیش‌فرض 500
- `MEHRAN_STUDIO_MIN_FREE_BYTES`: حداقل فضای آزاد، پیش‌فرض 2 GiB

## API

- `GET /health`: وضعیت کنترل‌پلین، مدل محلی و فضای آزاد
- `GET /v1/projects`: فهرست پروژه‌ها
- `POST /v1/projects`: ایجاد پیش‌نویس پروژه با JSON
- `POST /v1/jobs`: تا زمان نصب و آزمون موتور محلی، عمداً `503` برمی‌گرداند؛ job ساخته نمی‌شود و هزینه‌ای ثبت نمی‌شود.

## تست

```bash
python3 -m unittest discover -s engine -p 'test_*.py' -v
```

## مسیر توسعه بعدی

۱. تکمیل API و اتصال امن رابط استودیو به این کنترل‌پلین  
۲. طراحی قرارداد runtime و صف محدود پردازش  
۳. ارزیابی مدل‌های متن‌باز تولید موسیقی و مجوز استفادهٔ تجاری آن‌ها  
۴. نصب مدل فقط روی سخت‌افزار تحت کنترل MEHRAN و اجرای آزمون‌های محلی  
۵. فعال‌سازی jobها فقط پس از تست سلامت، محدودیت منابع و توقف قطعی در سقف مصرف

نکته: نرم‌افزار متن‌باز هزینهٔ مجوز/API را حذف می‌کند، اما برق، سخت‌افزار، اینترنت و فضای ذخیره‌سازی همچنان منابع واقعی‌اند. این کنترل‌پلین برای عبور از سقف منابع، پرداخت خودکار یا سرویس جایگزین پولی طراحی نشده است.
